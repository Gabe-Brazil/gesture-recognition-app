
Command format that the webapp sends to Ably

cmd: any valid command in `command_list.json`
id: generated by crypto.randomUUID() in browser, simply there to differentiate unique commands
ts: timestamp of message (milliseconds since Jan 1 1970, number created by Date.now() in javascript)
gesture: any valid gesture in `gesture_labels.json`
confidence: number from 0-1 which states how sure model is of its prediction

EXAMPLE:

{
  "cmd": "NEXT",
  "id": "3f8a2c1e-9b4d-4e0a-8f6b-2d7c5a1e9b30",
  "ts": 1761717600000,
  "gesture": "thumbs_up",
  "confidence": 0.94
}
